# LEARNING OUTCOME 1: IDENTIFY & INTERACT WITH GENERATIVE AI

### Information Sheet 1.1

**What is Generative AI?**
Generative AI is a type of artificial intelligence that can create new content —
text, images, audio, code, or video — based on patterns learned from data. You
interact with it using **prompts** (instructions written in natural language).

**Common Generative AI Tools:**

| Tool | Primary Use |
|------|-------------|
| ChatGPT / Claude / Gemini | Text generation, Q&A, writing, coding |
| Midjourney / DALL·E | Image generation |
| GitHub Copilot | Code generation |
| ElevenLabs | Voice / audio generation |

**A prompt has three basic parts:**
1. **Instruction** – what you want the AI to do
2. **Context** – background information it needs
3. **Format** – how you want the answer presented

# LEARNING OUTCOME 2: ADJUST PROMPTS & RESOLVE BIAS

### Information Sheet 2.1

**Why adjust prompts?**
The first answer is not always the best. **Prompt refinement** means improving
your prompt to get clearer, more accurate, and more useful results.

**Techniques to adjust prompts:**
- **Be specific** – add details, numbers, and constraints.
- **Add a role** – "Act as a teacher…"
- **Set the format** – "Answer in a table / bullet points."
- **Give an example** – show the AI what you expect.

**What is bias?**
Bias is an unfair or one-sided result. AI can reflect bias from its training
data or from how a prompt is worded. Example of a biased prompt:
> ❌ "Why are programmers always men?"

A neutral version:
> ✅ "Describe the typical skills of a programmer."

# LEARNING OUTCOME 3: ASSESS AI-GENERATED OUTPUTS

### Information Sheet 3.1

**Never trust blindly — always assess.**
AI can produce confident but incorrect answers ("hallucinations"). Evaluate
every output before using it.

**Criteria for assessing AI output:**

| Criteria | Question to Ask |
|----------|-----------------|
| **Accuracy** | Are the facts correct and verifiable? |
| **Relevance** | Does it answer what I actually asked? |
| **Completeness** | Is anything important missing? |
| **Bias / Fairness** | Is it neutral and respectful? |
| **Clarity** | Is it easy to understand? |

**Golden rule:** Verify important facts with a reliable source before using AI
output in real work.
